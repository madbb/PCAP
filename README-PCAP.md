# PCAP - Certified Associate in Python Programming

Kursmaterialien und Prüfungsvorbereitung für die PCAP-Zertifizierung des Python Institute.

## Projektübersicht

Dieses Repository enthält die Kursmaterialien für die PCAP-Zertifizierung (Certified Associate in Python Programming): Übungsaufgaben, Klausuren und einen Fragenpool zur Prüfungsvorbereitung. Die Inhalte sind als Jupyter-Book-Site aufgebaut und werden über GitHub Pages veröffentlicht.

| Eigenschaft | Details |
|---|---|
| Zertifizierung | PCAP - Certified Associate in Python Programming |
| Sprache | Deutsch |
| Format | Jupyter-Book-Site |
| Veröffentlichung | GitHub Pages, Deployment über deploy.bat |

## Inhalte

### Übungsmaterial

Notebooks zu den zentralen PCAP-Prüfungsthemen:

- Objektorientierte Programmierung (OOP)
- Module und Pakete
- Ein- und Ausgabe (I/O)
- Strings und Textverarbeitung

### Prüfungsvorbereitung

- Mehrere vollständige Klausuren im Prüfungsformat
- Ein zusammenfassender Fragenpool über alle Themenbereiche
- Sämtlicher Code wird vor Aufnahme in die Materialien lauffähig geprüft

## Nutzung

### Site lokal bauen

Die Site basiert auf Jupyter Book. Mit den Jupyter-Book-Tools lässt sich die Site lokal bauen und ansehen.

### Deployment

`deploy.bat` automatisiert den Build- und Veröffentlichungsschritt für GitHub Pages.
