Aufgaben: Exceptions Grundlagen

Development Expert Python  |  PCAP 2.1  |  Kapitel 5: Exceptions  |  Notebook 05a

Aufgabe 1 try/except: Grundstruktur

  1. Schreibe eine Funktion dividiere(a, b), die a / b zurueckgibt. Fange ZeroDivisionError ab und gib in diesem Fall None zurueck.

  2. Teste:

print(dividiere(10, 2))   # 5.0
print(dividiere(10, 0))   # None

  1. Schreibe eine Funktion lies_zahl(text), die int(text) zurueckgibt. Fange ValueError ab und gib -1 zurueck.

  2. Erklaere als Kommentar: Was passiert im try-Block nach dem Fehler? Wird der restliche Code im try-Block noch ausgefuehrt?

Aufgabe 2 Mehrere except-Bloecke

  1. Schreibe eine Funktion verarbeite(daten, index), die:

    • daten[index] abruft

    • das Ergebnis in einen int umwandelt

    • das Ergebnis durch daten[0] dividiert Fange IndexError, ValueError und ZeroDivisionError in separaten except-Bloecken ab. Jeder Block gibt eine passende Meldung aus und gibt None zurueck.

  2. Teste mit:

daten = [2, '8', 'keine_zahl', 0]
print(verarbeite(daten, 1))    # 8 / 2 = 4.0
print(verarbeite(daten, 2))    # ValueError
print(verarbeite(daten, 99))   # IndexError

  1. Ergaenze: Was passiert bei verarbeite([0, '4'], 1)? Erklaere als Kommentar.

Aufgabe 3 Mehrere Exceptions in einem Block

  1. Schreibe eine Funktion sichere_berechnung(text, divisor), die:

    • int(text) berechnet

    • das Ergebnis durch divisor dividiert Fange ValueError und ZeroDivisionError in einem einzigen except-Block als Tupel ab: except (ValueError, ZeroDivisionError). Gib im Fehlerfall 0 zurueck.

  2. Teste alle drei Faelle: gueltige Eingabe, ungueltige Eingabe, Division durch Null.

  3. Erklaere als Kommentar: Wann macht es Sinn, Exceptions zu gruppieren, und wann braucht man separate Bloecke?

Aufgabe 4 else und finally

  1. Schreibe eine Funktion lade_held(name) mit folgendem Dictionary:

HELDEN = {'Aldric': 100, 'Lyria': 80, 'Thorn': 90}

  • Im try-Block: Zugriff auf HELDEN[name]

  • Im except KeyError-Block: Meldung 'Held nicht gefunden', return None

  • Im else-Block: Meldung 'Held geladen', return der HP-Wert

  • Im finally-Block: Meldung 'Ladevorgang abgeschlossen' (immer)

  1. Teste mit einem bekannten und einem unbekannten Namen.

  2. Erklaere als Kommentar: In welcher Reihenfolge werden die Bloecke ausgefuehrt a) wenn kein Fehler auftritt und b) wenn ein Fehler auftritt?

Aufgabe 6 Reihenfolge der except-Bloecke

  1. Fuehre den folgenden Code aus und erklaere das Ergebnis:

try:
    x = 1 / 0
except Exception:
    print('Exception gefangen')
except ZeroDivisionError:
    print('ZeroDivisionError gefangen')

  1. Erklaere als Kommentar: Warum wird ZeroDivisionError nie erreicht?

  2. Korrigiere den Code so, dass die spezifischste Exception zuerst steht.

  3. Schreibe eine Funktion sicher_teilen(a, b) mit drei except-Bloecken in der richtigen Reihenfolge: ZeroDivisionError, ArithmeticError, Exception. Teste mit je einem Fall der jeden Block ausloeser. Hinweis: ArithmeticError ist die Elternklasse von ZeroDivisionError.

Aufgabe 7 raise: Exceptions ausloesen

  1. Schreibe eine Funktion setze_hp(wert), die prueft:

    • wert muss ein int sein, sonst TypeError

    • wert muss zwischen 0 und 500 liegen, sonst ValueError

    • Bei gueltiger Eingabe: gibt wert zurueck

  2. Schreibe eine Funktion setze_staerke(wert) mit denselben Pruefungen (Bereich 1-100).

  3. Teste alle Fehlerfaelle mit try/except und gib die Fehlermeldungen aus.

  4. Schreibe eine Funktion weitergeben(wert), die setze_hp(wert) aufruft. Fange den Fehler ab, gib eine eigene Meldung aus, und wirf die Exception mit raise (ohne Argument) weiter.

  5. Erklaere als Kommentar: Was ist der Unterschied zwischen raise (ohne Argument) und raise ValueError('...')?

Aufgabe 8 assert

  1. Schreibe eine Funktion teile_party(helden, gruppen), die:

    • Mit assert prueft: len(helden) > 0 und gruppen >= 1

    • Die Helden moeglichst gleichmaessig auf die Gruppen verteilt

    • Eine Liste von Listen zurueckgibt

  2. Teste:

helden = ['Aldric', 'Lyria', 'Thorn', 'Sera', 'Bjorn']
print(teile_party(helden, 2))   # zwei Gruppen
print(teile_party(helden, 3))   # drei Gruppen

  1. Teste die assert-Verletzungen:

try:
    teile_party([], 2)
except AssertionError as e:
    print(e)

  1. Erklaere als Kommentar: Was ist der konzeptionelle Unterschied zwischen assert und raise ValueError? Wann setzt man was ein?

Aufgabe 9 Fehler finden: Exception-Handling

Im folgenden Code stecken vier Fehler. Finde und korrigiere alle vier.

def berechne(werte, index):
    try:
        ergebnis = werte[index] / werte[0]
    except IndexError, ZeroDivisionError:   # Fehler 1
        return None
    except Exception:                       # Fehler 2: steht vor spezifischeren Bloecken
        return -1
    except ValueError:
        return -2
    else:
        print('Kein Fehler')
        return ergebnis
    finally:
        return 0                            # Fehler 3: ueberschreibt alle Rueckgaben

werte = [4, 8, 'x']
raise berechne(werte, 0)                    # Fehler 4
Aufgabe 10 Kombination: Eingabe-Validator

Schreibe eine Funktion held_erstellen(name, hp_text, staerke_text), die Nutzereingaben (als Strings) validiert und einen Held-Dictionary zurueckgibt.

Anforderungen:

  • name darf nicht leer sein (assert)

  • hp_text muss in int umwandelbar sein (ValueError abfangen)

  • hp_text als int muss zwischen 1 und 500 liegen (raise ValueError)

  • staerke_text muss in int umwandelbar sein

  • staerke_text als int muss zwischen 1 und 100 liegen

  • Im else-Block: Held-Dictionary erstellen und zurueckgeben

  • Im finally-Block: Meldung 'Validierung abgeschlossen'

Teste alle Fehlerfaelle einzeln:

print(held_erstellen('Aldric', '100', '15'))  # Erfolg
print(held_erstellen('', '100', '15'))         # AssertionError
print(held_erstellen('Aldric', 'abc', '15'))   # ValueError: kein int
print(held_erstellen('Aldric', '999', '15'))   # ValueError: Bereich
