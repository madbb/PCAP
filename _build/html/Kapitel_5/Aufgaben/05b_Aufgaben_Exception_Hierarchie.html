Aufgabe 10 Kombination: Fehlerprotokoll

Schreibe eine Funktion verarbeite_batch(eingaben), die eine Liste von Strings entgegennimmt und jede als Zahl versucht zu verarbeiten.

Anforderungen:

  • Jede Eingabe wird in int umgewandelt und quadriert

  • Fehler unterbrechen nicht die gesamte Verarbeitung

  • Die Funktion gibt ein Dictionary zurueck:

    • 'ergebnisse': Liste der erfolgreichen Werte

    • 'fehler': Liste von Tupeln (eingabe, fehlertyp, meldung)

  • Nutze type(e).__name__ fuer den Fehlertyp und str(e) fuer die Meldung

Teste:

ergebnis = verarbeite_batch(['4', 'abc', '7', '', '3'])
print('Ergebnisse:', ergebnis['ergebnisse'])  # [16, 49, 9]
print('Fehler:', ergebnis['fehler'])          # 2 Fehler
