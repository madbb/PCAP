PCAP Übungsklausur#

40 Multiple-Choice-Fragen – Themen: List Comprehension / Lambda / Map / Filter, Strings, Exceptions, OOP, Vererbung, Module & Pakete, Introspektion.

Jede Frage hat genau eine richtige Antwort.

Block 1: List Comprehension, Lambda, Map, Filter#

Frage 1

Was ist die Ausgabe des folgenden Codes?

print([x**2 for x in range(6) if x % 2 != 0])

A) [1, 4, 9, 16, 25]

B) [1, 9, 25]

C) [0, 4, 16]

D) [1, 9, 25, 36]

Frage 2

Was gibt der folgende Code aus?

print(list(map(lambda x: x[::-1], ['abc', 'de', 'f'])))

A) ['abc', 'de', 'f']

B) ['cba', 'ed', 'f']

C) ['f', 'ed', 'cba']

D) ['cba', 'de', 'f']

Frage 3

Was ist die Ausgabe?

nums = [3, 1, 4, 1, 5]
print(list(filter(lambda x: x > 2, nums)))

A) [3, 4, 5]

B) [1, 1]

C) [3, 4, 1, 5]

D) [4, 5]

Frage 4

Was gibt dieser Code aus?

f = lambda x, y=10: x + y
print(f(5))

A) 5

B) 10

C) 15

D) TypeError

Frage 5

Was ist die Ausgabe?

lst = [[1, 2], [3, 4], [5]]
print([x for sub in lst for x in sub if x % 2 == 0])

A) [2, 4]

B) [1, 3, 5]

C) [2, 4, 5]

D) [[2], [4]]

Frage 6

Was gibt der Code aus?

funcs = [lambda x, n=n: x * n for n in range(1, 4)]
print([f(3) for f in funcs])

A) [9, 9, 9]

B) [3, 3, 3]

C) [3, 6, 9]

D) [1, 2, 3]

Frage 7

Was gibt der folgende Code aus?

from functools import reduce
print(reduce(lambda a, b: a * b, [1, 2, 3, 4]))

A) 10

B) 24

C) 12

D) 6

Frage 8

Was ist das Ergebnis?

d = {x: x**2 for x in range(4) if x != 2}
print(d)

A) {0: 0, 1: 1, 2: 4, 3: 9}

B) {1: 1, 3: 9}

C) {0: 0, 1: 1, 3: 9}

D) {0: 0, 2: 4, 3: 9}

B) True generic

C) True woof

D) False generic

C) 0

D) 42

Block 5: Vererbung#

Frage 26

Was gibt der Code aus?

class A:
    def greet(self):
        return 'A'

class B(A):
    def greet(self):
        return super().greet() + 'B'

print(B().greet())

A) B

B) AB

C) BA

D) A

Frage 27

Was ist die Ausgabe?

class X:
    def __init__(self, n):
        self.n = n

    def __str__(self):
        return f'X({self.n})'

print(str(X(5)))

A) X

B) 5

C) X(5)

D) X object

class P:

        return 'Q'

    pass

print(R().run())

A) P

B) R

C) Q

D) AttributeError

class Shape:
