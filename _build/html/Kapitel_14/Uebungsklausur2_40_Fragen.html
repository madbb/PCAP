PCAP Übungsklausur 2#

40 Multiple-Choice-Fragen – Schwerpunkte nach offiziellem Syllabus PCAP-31-03: Module & Pakete, Exceptions, Strings, OOP (inkl. Vererbung, MRO, Name Mangling), Closures, List Comprehensions.

Genau eine Antwort ist richtig. Bearbeitungszeit: 60 Minuten.

B) caught as AppError

Frage 11

Was gibt der Code aus?

result = []

    try:
        if i == 1:
            raise RuntimeError
        result.append(i)
    except RuntimeError:
        result.append('err')
print(result)

A) [0, 2]

B) [0, 1, 2]

C) [0, 'err', 2]

D) ['err']

Sektion 4: Object-Oriented Programming#

Frage 21

Was gibt der Code aus?

class Dog:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f'Dog: {self.name}'

d = Dog('Rex')
print(str(d))

A) Rex

B) Dog

C) Dog: Rex

D) <__main__.Dog object>

B) False

C) AttributeError

D) None

Frage 25

Was gibt der Code aus?

class Animal:
    def __init__(self, name):
        self.name = name

class Cat(Animal):
    def __init__(self, name, indoor):
        super().__init__(name)
        self.indoor = indoor

c = Cat('Mimi', True)
print(c.name, c.indoor)

A) None True

B) Mimi False

C) Mimi True

D) AttributeError

Frage 26

Was ist die Ausgabe?

class Foo:
    def method(self):
        return 'Foo'

class Bar(Foo):
    def method(self):
        return super().method() + 'Bar'

class Baz(Bar):
    pass

print(Baz().method())

A) Baz

B) FooBar

C) BarFoo

D) Bar

Frage 27

Was gibt der Code aus? (MRO / Mehrfachvererbung)

class Left:
    def who(self):
        return 'Left'

class Right:
    def who(self):
        return 'Right'

class Child(Left, Right):
    pass

print(Child().who())

B) Right

C) Left Right

D) AttributeError

class Counter:

    def get_count(cls):
        return cls._count

Counter()
Counter()
print(Counter.get_count())

B) 1

C) 2

D) 3

D) True 6

Sektion 5: Closures, List Comprehensions, Lambda#

Frage 35

def outer(x):
    def inner(y):
        return x + y
    return inner

add5 = outer(5)
print(add5(3))

B) 8

C) 3

D) TypeError

Frage 36

Was ist die Ausgabe?

def make_multiplier(n):
    return lambda x: x * n

double = make_multiplier(2)
print(double(7))

B) 7

C) 14

D) 9

matrix = [[1, 2], [3, 4], [5, 6]]

D) [[2], [4], [6]]
