MODUL_INFO = "String Utility Modul v1.0"

def umkehren(s):
    return s[::-1]

def ist_palindrom(s):
    s_lower = s.lower()
    return s_lower == s_lower[::-1]

Aufgabe 10:#

Eigenes Modul mini_random_tools.py

Schritt 1:

Erstelle eine neue Python-Datei namens mini_random_tools.py im selben Verzeichnis wie dieses Hauptskript. Füge folgenden Inhalt in mini_random_tools.py ein:

import random

MODUL_NAME = "Mini Random Tools"

def wuerfeln(anzahl_wuerfe=1):
    '''Simuliert das Würfeln mit einem Standard-Würfel.'''
    ergebnisse = []
    for _ in range(anzahl_wuerfe):
        wurf = random.randint(1, 6)
        ergebnisse.append(wurf)
    return ergebnisse

def zufalls_element_aus_liste(input_liste):
    '''Wählt ein zufälliges Element aus der gegebenen Liste.'''
    if not input_liste: # Überprüft, ob die Liste leer ist
        return None
    return random.choice(input_liste)

if __name__ == "__main__":
    print(f"--- {MODUL_NAME} wird direkt ausgeführt ---")
    
    print("Test Würfeln (3x):", wuerfeln(3))
    print("Test Würfeln (1x):", wuerfeln()) # Standardwert nutzen

    test_liste = ["rot", "grün", "blau"]
    print(f"Test Zufallselement aus {test_liste}:", zufalls_element_aus_liste(test_liste))
    
    leere_liste = []
    print(f"Test Zufallselement aus {leere_liste}:", zufalls_element_aus_liste(leere_liste))
    print(f"--- Ende Selbsttest {MODUL_NAME} ---")

Schritt 2:

  1. Importiere dein erstelltes Modul mini_random_tools komplett.

  2. Importiere zusätzlich spezifisch die Funktion zufalls_element_aus_liste aus mini_random_tools unter dem Alias pick_one.

  3. Gegeben ist eine Liste von möglichen Aktionen: aktionen = ["Angriff", "Verteidigung", "Zauber", "Ausruhen"]

  4. Simuliere 5 Würfelwürfe mit der Funktion mini_random_tools.wuerfeln(). Speichere das Ergebnis (eine Liste von Zahlen) in wuerfel_ergebnisse und gib es aus.

  5. Wähle mit der importierten Alias-Funktion pick_one eine zufällige Aktion aus der aktionen Liste aus. Speichere das Ergebnis in gewaehlte_aktion und gib es aus.

  6. Gib den mini_random_tools.MODUL_NAME aus.
