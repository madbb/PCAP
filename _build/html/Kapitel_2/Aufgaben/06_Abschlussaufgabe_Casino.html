PCAP-Prüfungshinweise: Section 1

  • import as macht den Originalnamen ungültig. import platform as plt → platform.system() ist dann ungültig.
  • floor() vs int() bei negativen Zahlen: floor(-7.3) = -8, aber int(-7.3) = -7
  • sample() vs choices(): sample = ohne Zurücklegen, choices = mit Zurücklegen
  • python_version_tuple() gibt immer Strings zurück, keine ints.
  • dir(modul) gibt eine Liste von Strings zurück, alphabetisch sortiert
  • seed() macht Zufallssequenzen reproduzierbar (wichtig für Tests)
