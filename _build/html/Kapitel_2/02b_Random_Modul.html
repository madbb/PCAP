Random Modul#

Das random-Modul

Development Expert Python / PCAP  |  Kapitel 2: Module  |  Notebook 02a

Legende

PCAP 1.3Inhalt wird in der Pruefung abgefragt
KursinhaltPraxiswissen fuer den Kurs, nicht pruefungsrelevant
KursinhaltEinleitung

Viele Programme brauchen Zufallswerte – ob fuer Simulationen, Spiele, Tests oder das zufaellige Auswaehlen aus Daten. Python stellt dafuer das random-Modul bereit. Es erzeugt sogenannte Pseudozufallszahlen: Zahlen, die zufaellig wirken, aber auf einem deterministischen Algorithmus basieren (dem Mersenne-Twister-Generator).

Das random-Modul ist vorinstalliert und kann direkt verwendet werden.

Kursinhalt1. Die Bibliothek importieren

Um die Funktionen des random-Moduls zu nutzen, musst du es zunaechst importieren.

import random
# oder gezielt einzelne Funktionen:
from random import randint, choice, shuffle

Wenn du nur bestimmte Funktionen brauchst, ist der gezielte Import effizienter und macht den Code lesbarer.

Beispiel:

from random import randint
print(randint(1, 10))

import random
PCAP 1.32. Die Funktion seed()

Der Zufallsgenerator startet immer mit einem sogenannten Startwert (Seed). Normalerweise nutzt Python dafuer die aktuelle Systemzeit – das Ergebnis ist also bei jedem Aufruf verschieden.

Mit seed() kannst du diesen Startwert selbst festlegen. Das macht die Ausgabe reproduzierbar – nuetzlich fuer Tests, Debugging oder Demonstrationen.

random.seed(a=None, version=2)

  • a → Der Startwert. Bei None (Standard) wird die Systemzeit verwendet.

  • version → Interner Parameter, normalerweise nicht aendern.

Beide Durchlaeufe liefern dieselben Zahlen, weil der Seed identisch ist.

# Teste es selber
import random

random.seed(42)
print(random.randint(1, 100))
print(random.randint(1, 100))

random.seed(42)
print(random.randint(1, 100))
print(random.randint(1, 100))
PCAP 1.33. Die Funktion random()

Die grundlegendste Funktion des Moduls heißt genauso wie das Modul selbst: random().

Sie gibt einen zufaelligen Gleitkommawert zurueck – immer im Bereich:

0.0 <= x < 1.0

Die obere Grenze 1.0 ist ausgeschlossen.

from random import random

print(random())
print(random())
print(random())

Moegliche Ausgabe:

0.6394267984578837
0.025010755222666936
0.27502931836911926

# Teste es selber
from random import random

print(random())
print(random())
print(random())

Praxisbeispiel: Zufaelligen Prozentwert erzeugen

import random

wahrscheinlichkeit = random.random() * 100
print(f"Zufaelliger Prozentwert: {wahrscheinlichkeit:.2f}%")
Kursinhalt4. Die Funktion uniform()

Wenn du einen Gleitkommawert in einem eigenen Bereich brauchst, verwende uniform().

random.uniform(a, b)

  • Gibt einen Wert x zurueck, sodass a <= x <= b.

  • Beide Grenzen koennen im Ergebnis vorkommen (im Gegensatz zu random()).

# Teste es selber
import random

print(random.uniform(1.5, 4.5))
print(random.uniform(0, 100))

Praxisbeispiel: Zufaellige Temperatur zwischen 36.0 und 37.5 Grad simulieren

import random

temperatur = random.uniform(36.0, 37.5)
print(f"Gemessene Temperatur: {temperatur:.1f} °C")
Kursinhalt5. Die Funktion randint()

Fuer ganze Zufallszahlen in einem bestimmten Bereich gibt es randint().

random.randint(a, b)

  • Gibt eine ganzzahlige Zufallszahl zurueck: a <= x <= b.

  • Wichtig: Beide Grenzen sind inklusive – also koennen a und b im Ergebnis vorkommen.

# Teste es selber
import random

print(random.randint(1, 6))
print(random.randint(0, 1))

Praxisbeispiel: Wuerfelwurf simulieren

import random

wurf = random.randint(1, 6)
print(f"Wuerfelwurf: {wurf}")

# Zehn Wuerfe
wuerfe = [random.randint(1, 6) for _ in range(10)]
print("Zehn Wuerfe:", wuerfe)
print("Summe:", sum(wuerfe))
Kursinhalt6. Die Funktion randrange()

randrange() ist flexibler als randint(): Du kannst zusaetzlich eine Schrittweite angeben.

random.randrange(start, stop, step=1)

  • start → Startwert (inklusive)

  • stop → Endwert (exklusive – wie bei range())

  • step → Schrittweite (Standard: 1)

# Teste es selber
import random

print(random.randrange(0, 10))
print(random.randrange(0, 10, 2))
print(random.randrange(10, 100, 10))

Praxisbeispiel: Zufaellige gerade Hausnummer erzeugen

import random

hausnummer = random.randrange(2, 200, 2)
print(f"Zufaellige gerade Hausnummer: {hausnummer}")
PCAP 1.37. Die Funktion choice()

Mit choice() waehlst du ein einzelnes zufaelliges Element aus einer Sequenz (Liste, Tupel, String).

random.choice(seq)

  • seq → Eine nicht-leere Sequenz

  • Gibt genau ein Element zurueck

  • Bei leerer Sequenz: IndexError

# Teste es selber
import random

farben = ['rot', 'gruen', 'blau', 'gelb']
print(random.choice(farben))

print(random.choice('Python'))

Praxisbeispiel: Zufaelliges Menuegericht auswaehlen

import random

menu = ['Pizza', 'Sushi', 'Pasta', 'Burger', 'Salat']
gericht = random.choice(menu)
print(f"Heutiges Mittagessen: {gericht}")
PCAP 1.38. Die Funktion sample()

Wenn du mehrere Elemente ohne Wiederholung auswaehlen willst, ist sample() die richtige Wahl.

random.sample(population, k)

  • population → Die Sequenz, aus der gewaehlt wird

  • k → Anzahl der Elemente, die ausgewaehlt werden sollen

  • Jedes Element kann nur einmal vorkommen (keine Wiederholung)

  • Wenn k groesser als die Laenge der Sequenz: ValueError

# Teste es selber
import random

zahlen = list(range(1, 50))
print(random.sample(zahlen, 6))

Praxisbeispiel: Drei Gewinner aus einer Teilnehmerliste ziehen

import random

teilnehmer = ['Anna', 'Ben', 'Clara', 'David', 'Eva', 'Felix', 'Greta', 'Hans']
gewinner = random.sample(teilnehmer, 3)
print("Gewinner:")
for platz, name in enumerate(gewinner, start=1):
    print(f"  Platz {platz}: {name}")
Kursinhalt9. Die Funktion shuffle()

shuffle() mischt eine Liste in-place – also direkt in der Originalliste, ohne eine neue zu erstellen.

random.shuffle(x)

  • x → Die Liste, die gemischt werden soll

  • Gibt None zurueck – der Rueckgabewert ist nicht die gemischte Liste!

  • Funktioniert nur mit veraenderbaren Sequenzen (Listen, nicht Tupel)

# Teste es selber
import random

karten = ['Ass', 'Koenig', 'Dame', 'Bube', '10']
print("Vorher:", karten)

random.shuffle(karten)
print("Nachher:", karten)

Haeufiger Fehler: shuffle() gibt None zurueck – diesen Code nicht schreiben:

import random

karten = ['Ass', 'Koenig', 'Dame']

# FALSCH -- ergebnis ist None!
ergebnis = random.shuffle(karten)
print(ergebnis)  # None

# RICHTIG -- die originale Liste wurde veraendert
print(karten)

Praxisbeispiel: Fragen fuer ein Quiz zufaellig mischen

import random

fragen = [
    'Was ist die Hauptstadt von Frankreich?',
    'Wie viele Planeten hat unser Sonnensystem?',
    'Was ergibt 7 x 8?',
    'In welchem Jahr fiel die Berliner Mauer?'
]

random.shuffle(fragen)
print("Quiz-Reihenfolge:")
for i, frage in enumerate(fragen, start=1):
    print(f"  {i}. {frage}")
PCAP 1.310. Die Funktion choices()

choices() waehlt mehrere Elemente mit Wiederholung aus – im Gegensatz zu sample().

random.choices(population, weights=None, k=1)

  • population → Die Sequenz, aus der gewaehlt wird

  • weights → Optionale Gewichtung (haeufigere Elemente wahrscheinlicher)

  • k → Anzahl der Ergebnisse

  • Ein Element kann mehrfach vorkommen

# Teste es selber
import random

print(random.choices(['Kopf', 'Zahl'], k=5))

print(random.choices(['rot', 'blau'], weights=[3, 1], k=10))

Praxisbeispiel: Gluecksrad mit unterschiedlichen Gewinnchancen

import random

preise = ['Hauptgewinn', '50 Euro', '10 Euro', 'Niete']
wahrscheinlichkeit = [1, 5, 20, 74]  # Prozent-aehnliche Gewichtung

ergebnis = random.choices(preise, weights=wahrscheinlichkeit, k=1)[0]
print(f"Das Gluecksrad zeigt: {ergebnis}")
