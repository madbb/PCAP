Aufgaben: bytearray

Development Expert Python  |  PCAP 5.5  |  Kapitel 7: I/O

Aufgabe 1 bytearray erstellen und Grundeigenschaften

  1. Erstelle folgende bytearray-Objekte und gib jeweils type() und Inhalt aus:

    • Aus einem String: bytearray('Hallo', 'utf-8')

    • Aus einem bytes-Literal: bytearray(b'Python')

    • Aus einer Liste von Ganzzahlen: bytearray([72, 101, 108, 108, 111])

    • Leer mit vorgegebener Laenge: bytearray(5)

  2. Gib von jedem Objekt len() aus.

  3. Gib aus was bytearray(5) als Werte enthaelt. Was steht in einem leeren bytearray?

  4. Erklaere als Kommentar: Was ist ein Byte-Wert? In welchem Zahlenbereich muss jedes Element eines bytearray liegen?

Aufgabe 2 bytearray vs. bytes: Mutabilitaet

  1. Erstelle b = b'Hallo' und ba = bytearray(b'Hallo').

  2. Versuche b[0] = 72. Fange den Fehler ab und gib die Fehlermeldung aus.

  3. Fuehre ba[0] = 104 aus (Kleinbuchstabe 'h'). Gib ba danach aus.

  4. Erklaere als Kommentar den Unterschied:

    • Was ist b[0]? Welchen Typ hat es?

    • Was ist ba[0]? Welchen Typ hat es?

    • Warum kann man ba[0] setzen, b[0] aber nicht?

  5. Versuche ba[0] = 300. Was passiert? Welcher Fehler wird geworfen?

Aufgabe 3 Indexing, Slicing und Iteration

Gegeben: ba = bytearray(b'Aetherion')

  1. Gib den ersten und letzten Byte-Wert aus. Was ist der Typ?

  2. Gib ba[2:6] aus. Was ist der Typ des Ergebnisses?

  3. Iteriere mit einer for-Schleife ueber ba. Gib pro Iteration den Byte-Wert und das zugehoerige Zeichen mit chr() aus.

  4. Wandle jeden Byte-Wert in ba in Grossschreibung um: Wenn der Wert im Bereich 97-122 (Kleinbuchstaben) liegt, ziehe 32 ab. Nutze eine Schleife mit Indexzugriff.

  5. Gib das Ergebnis als String aus: ba.decode('utf-8').

Aufgabe 4 Vorhersage: bytearray-Ausdruecke

Den Code nicht ausfuehren. Ergebnis als Kommentar schreiben, dann pruefen.

4.1

ba = bytearray(b'ABC')
print(ba[0])
print(type(ba[0]))
print(ba[0:2])
print(type(ba[0:2]))

4.2

ba = bytearray([65, 66, 67])
print(ba.decode('utf-8'))
ba[1] = 90
print(ba.decode('utf-8'))

4.3

ba = bytearray(b'Hallo')
b  = bytes(ba)
print(ba == b)
print(ba is b)
print(type(ba) == type(b))

4.4

ba = bytearray(3)
print(list(ba))
ba[0] = 255
ba[1] = 0
ba[2] = 128
print(list(ba))
Aufgabe 5 extend(), append() und Verkettung

  1. Erstelle ba = bytearray(b'Hallo').

  2. Haenge mit ba.append(33) ein Ausrufezeichen an (ASCII 33 = '!').

  3. Haenge mit ba.extend(b' Welt') einen weiteren String an.

  4. Erstelle ba2 = bytearray(b'!') und verbinde mit ba + ba2. Was ist der Typ des Ergebnisses?

  5. Was ist der Unterschied zwischen ba.append(65) und ba.extend(b'A')? Teste beide und erklaere als Kommentar.

  6. Versuche ba.append('A') (String statt int). Was passiert?

Aufgabe 6 bytearray in Binaerdateien schreiben und lesen

  1. Erstelle ein bytearray mit den Werten [10, 20, 30, 40, 50].

  2. Schreibe es mit Modus 'wb' in eine Datei werte.bin.

  3. Lies die Datei mit Modus 'rb' und speichere das Ergebnis. Gib Typ und Inhalt aus. Was ist der Unterschied zwischen dem gelesenen Objekt und dem urspruenglichen bytearray?

  4. Wandle das gelesene bytes-Objekt in ein bytearray um.

  5. Veraendere den dritten Wert auf 99 und schreibe die Datei neu. Lies zur Kontrolle erneut ein und pruefe mit assert.

Aufgabe 7 bytearray als Puffer: Binaerdaten veraendern

Ein typischer Anwendungsfall: Eine Binaerdatei einlesen, gezielt Bytes veraendern und zurueckschreiben – ohne die ganze Datei neu zu erstellen.

  1. Erstelle eine Binaerdatei spielstand.bin mit folgendem Inhalt:

daten = bytearray()
daten.extend(b'SAVE')   # 4 Bytes: Magic-Header
daten.append(3)         # 1 Byte:  Anzahl Helden
daten.extend([85, 60, 90])  # 3 Bytes: HP der Helden

  1. Lies die Datei als bytearray ein.

  2. Pruefe den Header: die ersten 4 Bytes muessen b'SAVE' ergeben. Nutze Slicing und Vergleich.

  3. Lies die Anzahl der Helden aus Byte-Index 4.

  4. Heile den ersten Helden: setze seinen HP-Wert (Index 5) auf 100.

  5. Schreibe das veraenderte bytearray zurueck in die Datei.

  6. Lies zur Kontrolle erneut ein und gib alle HP-Werte aus.

Aufgabe 8 Konvertierungen: bytes, bytearray, str

  1. Zeige den vollstaendigen Konvertierungskreis:

str -> bytes -> bytearray -> bytes -> str

Nutze .encode(), bytearray(), bytes(), .decode(). Starte mit text = 'Aetherion' und pruefe am Ende text == ergebnis. 2. Wandle bytearray([72, 97, 108, 108, 111]) in einen String um. Was steht darin? 3. Erstelle ba = bytearray(b'Python'). Wandle es in eine Liste von Ganzzahlen um mit list(ba). Wandle es zurueck mit bytearray(liste). 4. Was ist der Unterschied zwischen bytes(ba) und ba[:]? Vergleiche Typ und Inhalt.
