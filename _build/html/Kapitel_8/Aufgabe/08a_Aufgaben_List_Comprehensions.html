Aufgabe 1 Schleife zu Comprehension umschreiben

Schreibe jede der folgenden Schleifen als List Comprehension um. Pruefe mit == dass beide Varianten dasselbe Ergebnis liefern.

1.1

ergebnis = []
for x in range(10):
    ergebnis.append(x ** 2)

1.2

woerter = ['hallo', 'welt', 'python', 'aetherion']
ergebnis = []
for w in woerter:
    ergebnis.append(w.upper())

1.3

zahlen = [3, 7, 1, 9, 2, 8, 4, 6, 5]
ergebnis = []
for z in zahlen:
    ergebnis.append(z * 2 + 1)

1.4

helden = [{'name': 'Aldric', 'hp': 100}, {'name': 'Lyria', 'hp': 80}]
ergebnis = []
for h in helden:
    ergebnis.append(h['name'])

  3. Erstelle eine Liste aller HP-Werte die sowohl ueber 40 als auch unter 90 liegen.

  4. Gegeben:

woerter = ['Python', 'ist', 'eine', 'tolle', 'Sprache', 'fuer', 'alle']

Erstelle eine Liste aller Woerter die laenger als 4 Zeichen sind. 5. Erstelle eine Liste aller Woerter die mit einem Grossbuchstaben beginnen. Nutze w[0].isupper().

Aufgabe 3 if-else im Ausdruck: transformieren statt filtern

Das if am Ende filtert. Das if im Ausdruck transformiert – alle Elemente bleiben.

Gegeben: helden_hp = [100, 45, 80, 12, 60, 95, 30, 71]

  1. Erstelle eine Liste die jeden Wert als 'verletzt' oder 'gesund' beschriftet (unter 50 = verletzt).

  2. Erstelle eine Liste die jeden Wert durch 0 ersetzt wenn er unter 30 liegt, sonst behaelt er seinen Wert (HP unter 30 gelten als besiegt).

  3. Erklaere als Kommentar den Unterschied zwischen:

a = [x for x in helden_hp if x > 50]       # Variante A
b = [x if x > 50 else 0 for x in helden_hp] # Variante B

Wie viele Elemente hat jeweils das Ergebnis?

Aufgabe 5 Verschachtelte Comprehensions: zwei for-Klauseln

  1. Erstelle alle moeglichen Paare aus zwei Listen:

farben  = ['rot', 'blau', 'gruen']
groessen = ['S', 'M', 'L']

Ergebnis: [('rot', 'S'), ('rot', 'M'), ...] – 9 Paare insgesamt. 2. Erstelle eine flache Liste aus einer verschachtelten:

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Ergebnis: [1, 2, 3, 4, 5, 6, 7, 8, 9] 3. Erstelle alle Paare aus einer Liste bei denen die Zahlen verschieden sind:

zahlen = [1, 2, 3, 4]
# [(1,2), (1,3), (1,4), (2,1), (2,3), ...]

  1. PCAP-Falle: Was ist der Unterschied zwischen diesen beiden?

a = [(x, y) for x in [1,2,3] for y in [4,5,6]]
b = [(x, y) for y in [4,5,6] for x in [1,2,3]]

Gib beide aus und erklaere die Reihenfolge als Kommentar.

laengen = [w: len(w) for w in ['hallo', 'welt']]

helden = [
