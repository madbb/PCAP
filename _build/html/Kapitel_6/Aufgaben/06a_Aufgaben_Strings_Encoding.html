Aufgaben: Strings, Encoding und Grundoperationen

Development Expert Python  |  PCAP 3.1 / 3.2  |  Kapitel 6: Strings  |  Notebook 06a

Aufgabe 1 ord() und chr()

  1. Gib den Unicode-Codepoint folgender Zeichen aus: 'A', 'a', 'Z', '0', ' '.

  2. Gib das Zeichen zu folgenden Codepoints aus: 65, 97, 48, 64, 128512.

  3. Zeige, dass ord() und chr() Umkehrfunktionen sind: chr(ord('X')) == 'X' und ord(chr(9999)) == 9999.

  4. Schreibe eine Funktion buchstabe_verschieben(zeichen, schritte), die einen Buchstaben um schritte Positionen im Alphabet verschiebt. Beispiel: buchstabe_verschieben('A', 3) ergibt 'D'.

  5. Erklaere als Kommentar: Warum ergibt 'A' < 'a' in Python True?

Aufgabe 2 ASCII und Unicode

  1. Gib alle druckbaren ASCII-Zeichen aus (Codepoints 32 bis 126). Format: '32: (Leerzeichen)', '65: A' usw.

  2. Pruefe: Welche der folgenden Zeichen liegen ausserhalb des ASCII-Bereichs? 'A', 'ä', '€', '中', '!' Schreibe eine Funktion ist_ascii(zeichen) die True zurueckgibt wenn der Codepoint zwischen 0 und 127 liegt.

  3. Schreibe eine Funktion nur_ascii(text), die alle Nicht-ASCII-Zeichen aus einem String entfernt und den bereinigten String zurueckgibt.

  4. Teste: nur_ascii('Hallo Wörld!') ergibt 'Hallo Wrld!'.

Aufgabe 3 encode() und decode()

  1. Encode den String 'Hallo' mit UTF-8. Gib den bytes-Wert und type() aus.

  2. Encode 'Straße' mit UTF-8 und mit Latin-1. Vergleiche die Laenge der Ergebnisse. Erklaere den Unterschied als Kommentar.

  3. Versuche 'Straße'.encode('ascii'). Fange den UnicodeEncodeError ab und gib die Fehlermeldung aus.

  4. Decode b'Hallo' zurueck zu einem String.

  5. Schreibe eine Funktion zeige_bytes(text, encoding='utf-8'), die jeden Buchstaben mit seinen Byte-Werten ausgibt:

H -> b'H' (1 Byte)
ä -> b'\xc3\xa4' (2 Bytes)
Aufgabe 4 Indexing und Slicing

Gegeben: text = 'Aetherion'

  1. Gib aus: erstes Zeichen, letztes Zeichen, zweitletztes Zeichen.

  2. Gib folgende Slices aus und erklaere jeden als Kommentar: text[2:6], text[:4], text[4:], text[-3:], text[::2], text[::-1]

  3. Strings sind immutable. Versuche text[0] = 'a', fange den Fehler ab und erklaere als Kommentar warum das nicht funktioniert.

  4. Schreibe eine Funktion kehre_um(text) die einen String umkehrt. Nutze Slicing, nicht reversed().

  5. Schreibe eine Funktion ist_palindrom(text) die prueft ob ein String vorwaerts und rueckwaerts gelesen gleich ist. Teste mit 'racecar', 'Aetherion', 'madam'.

Aufgabe 10 Kombination: Zeichenanalyse

Schreibe eine Funktion text_analysieren(text), die ein Dictionary zurueckgibt mit:

  • 'laenge': Anzahl aller Zeichen

  • 'buchstaben': Anzahl der Buchstaben (a-z, A-Z und Umlaute via isalpha())

  • 'ziffern': Anzahl der Ziffern (0-9)

  • 'ascii_anteil': Anteil der ASCII-Zeichen (0.0 bis 1.0)

  • 'haeufigste': das am haeufigsten vorkommende Zeichen (ohne Leerzeichen)

  • 'umkehrung': der Text rueckwaerts (Slicing)

Teste:

ergebnis = text_analysieren('Aetherion 42!')
print(ergebnis['laenge'])        # 13
print(ergebnis['ascii_anteil'])  # 1.0

ergebnis2 = text_analysieren('Straße 99')
print(ergebnis2['ascii_anteil'])  # < 1.0 wegen 'ß'
