Aufgabe 1 hasattr(): Faehigkeiten pruefen

Gegeben sind diese Klassen:

class Krieger:
    def __init__(self, name):
        self.name  = name
        self.waffe = 'Schwert'
    def angreifen(self): return f'{self.name} schlaegt zu!'

class Magierin:
    def __init__(self, name):
        self.name = name
        self.mana = 80
    def zaubern(self):  return f'{self.name} wirkt einen Zauber!'
    def heilen(self):   return f'{self.name} heilt!'

class Waldlaeufer:
    def __init__(self, name):
        self.name = name
    def angreifen(self): return f'{self.name} schiesst einen Pfeil!'
    def heilen(self):    return f'{self.name} braut einen Kraeutertrank!'

  1. Kopiere die Klassen in die Code-Zelle.

  2. Erstelle eine Gruppe: gruppe = [Krieger('Aldric'), Magierin('Lyria'), Waldlaeufer('Thorn')]

  3. Iteriere ueber die Gruppe. Rufe fuer jeden Charakter alle Faehigkeiten auf, die er hat (angreifen, zaubern, heilen). Nutze hasattr().

  4. Pruefe zusaetzlich: Welche Charaktere haben ein mana-Attribut? Gib den jeweiligen Wert aus.

  2. Lies den Wert von waffe mit getattr() aus. Speichere ihn in ausruestung.

  3. Lies mana mit getattr() aus. Nutze 'kein Mana' als Fallback-Wert.

  4. Setze mit setattr() ein neues Attribut ruestung = 'Plattenruestung'. Pruefe danach mit aldric.ruestung, dass es gesetzt wurde.

  5. Gegeben ist dieses Dictionary:

neue_ausruestung = {'waffe': 'Streitaxt', 'helm': 'Eisenhelm', 'schild': 'Turmschild'}

Setze alle Eintraege mit einer Schleife und setattr() auf aldric. Gib danach aldric.waffe, aldric.helm und aldric.schild aus. 6. Erklaere als Kommentar: Wann ist getattr(obj, name) nuetzlicher als obj.name?

Aufgabe 4 Vorhersage: isinstance() und issubclass()

Den Code nicht ausfuehren. Ausgabe als Kommentar schreiben, dann pruefen.

4.1

class Charakter: pass
class Held(Charakter): pass
class Krieger(Held): pass

aldric = Krieger()

print(isinstance(aldric, Krieger))
print(isinstance(aldric, Held))
print(isinstance(aldric, Charakter))
print(isinstance(aldric, object))
print(isinstance(aldric, str))

4.2

print(type(aldric) == Krieger)

4.3

print(issubclass(Krieger, Held))

print(issubclass(Held, Krieger))
