Aufgabe 1 Klassenvariable definieren und auslesen

  1. Schreibe eine Klasse Held mit:

    • einer Klassenvariablen gildenname = 'Die Silberne Klinge'

    • einem Konstruktor der name und hp als Instanzattribute speichert

  2. Erstelle zwei Objekte: aldric = Held('Aldric', 100) und lyria = Held('Lyria', 80).

  3. Gib folgende Werte aus und beobachte, was identisch ist:

    • Held.gildenname

    • aldric.gildenname

    • lyria.gildenname

  5. Erklaere als Kommentar: Warum aendern sich beide Instanzen gleichzeitig?

Aufgabe 8 Fehler finden: Klassen- vs. Instanzvariable

Im folgenden Code stecken drei Fehler. Finde und korrigiere alle drei. Schreibe die korrigierte Version in die Code-Zelle und erklaere jeden Fehler als Kommentar.

class Held:
    anzahl_helden = 0
    max_hp = 100

    def __init__(self, name, hp):
        self.name = name
        self.hp   = hp
        self.anzahl_helden += 1    # Fehler 1

    def heilen(self, menge):
        self.hp += menge
        if self.hp > self.max_hp:  # Fehler 2
            self.hp = max_hp       # Fehler 3

aldric = Held('Aldric', 80)
aldric.heilen(40)
print(aldric.hp)          # sollte 100 sein, nicht 120
print(Held.anzahl_helden) # sollte 1 sein

    • GILDENNAME = 'Die Silberne Klinge'

    • _staerke darf MIN_STAERKE nicht unterschreiten (clampen mit max())

aldric  = Held('Aldric', 300, 15)   # HP wird auf 200 begrenzt

print(aldric.hp())       # 200
print(schwach.staerke()) # 1
print(Held.GILDENNAME)   # Die Silberne Klinge

Aufgabe 10 Kombination: Gilden-Registry

  1. Schreibe eine Klasse Held mit einer Klassenvariablen _registry = [] (eine Liste, die alle erstellten Instanzen speichert).

  2. Im Konstruktor: Haenge self an Held._registry an.

  3. Schreibe eine Methode alle_helden(self), die Held._registry zurueckgibt.

  4. Schreibe eine Methode suche(self, name), die den Helden mit dem angegebenen Namen aus _registry zurueckgibt, oder None wenn nicht gefunden.

  5. Teste:

aldric = Held('Aldric', 'Krieger', 100)
lyria  = Held('Lyria',  'Magierin', 80)
thorn  = Held('Thorn',  'Waldlaeufer', 90)

print(len(aldric.alle_helden()))   # 3

gefunden = aldric.suche('Lyria')
print(gefunden.name)               # Lyria
print(gefunden.klasse)             # Magierin

print(aldric.suche('Mira'))        # None

  1. Erklaere als Kommentar: Warum ist _registry eine Klassenvariable und keine Instanzvariable? Was wuerde passieren, wenn sie in __init__ als self._registry = [] definiert waere?
