Aufgabe 1 Komposition: Waffe und Held

  1. Schreibe eine Klasse Waffe mit name, schaden, typ. __str__ gibt z.B. 'Eisenschwert (Nahkampf, 25 Schaden)' zurueck.

  2. Schreibe eine Klasse Held mit name, hp. self.waffe = None im Konstruktor. Methode ausruesten(waffe): setzt self.waffe und gibt eine Meldung aus. Methode angreifen(): gibt self.waffe.schaden zurueck wenn bewaffnet, sonst 5. __str__: zeigt Name, HP und aktuell ausgeruestete Waffe.

  3. Teste:

aldric  = Held('Aldric', 100)
schwert = Waffe('Eisenschwert', 25, 'Nahkampf')
axt     = Waffe('Streitaxt', 35, 'Nahkampf')

print(aldric.angreifen())   # 5 (Faustkampf)
aldric.ausruesten(schwert)
print(aldric.angreifen())   # 25
aldric.ausruesten(axt)      # Waffe tauschen
print(aldric)

  1. Erklaere als Kommentar: Warum waere Held(Waffe) per Vererbung falsch?

Aufgabe 2 Komposition: Inventar

  1. Schreibe eine Klasse Gegenstand mit name, typ und wert. __str__ gibt 'Heiltrank (Trank, Wert: 10)' zurueck.

  2. Erweitere Held um ein Inventar:

    • self.inventar = [] im Konstruktor

    • aufheben(gegenstand): fuegt Gegenstand-Objekt hinzu

    • ablegen(name): entfernt den Gegenstand mit dem angegebenen Namen. Gibt True zurueck wenn gefunden, sonst False.

    • inventar_anzeigen(): listet alle Gegenstaende auf

    • inventarwert(): gibt die Summe aller wert-Attribute zurueck

  3. Teste:

aldric    = Held('Aldric', 100)
heiltrank = Gegenstand('Heiltrank', 'Trank', 10)
schluessel = Gegenstand('Kelchschluessel', 'Schluessel', 5)

aldric.aufheben(heiltrank)
aldric.aufheben(schluessel)
aldric.inventar_anzeigen()
print(aldric.inventarwert())  # 15
aldric.ablegen('Heiltrank')
aldric.inventar_anzeigen()
Aufgabe 3 Dunder-Methoden: __len__, __contains__, __add__

  1. Schreibe eine Klasse Trupp, die eine Gruppe von Helden verwaltet. Intern speichert sie die Helden in self._helden = [].

  2. Implementiere:

    • __init__(self, *helden): nimmt beliebig viele Helden als Argumente

    • __len__: gibt Anzahl der Helden zurueck

    • __contains__: gibt True zurueck wenn der Held (per is) im Trupp ist

    • __add__: kombiniert zwei Trupps zu einem neuen

    • __iter__: erlaubt Iteration ueber den Trupp

    • __str__: gibt alle Heldennamen kommagetrennt aus

  3. Teste:

aldric = Held('Aldric', 100)
lyria  = Held('Lyria', 80)
thorn  = Held('Thorn', 90)

trupp1 = Trupp(aldric, lyria)
trupp2 = Trupp(thorn)

print(len(trupp1))           # 2
print(aldric in trupp1)      # True
print(thorn in trupp1)       # False

gesamt = trupp1 + trupp2
print(len(gesamt))           # 3

for held in gesamt:
    print(held.name)
Aufgabe 4 Dunder-Methoden: __eq__, __lt__, __repr__

  1. Schreibe eine Klasse Held mit name und kampfkraft (int).

  2. Implementiere:

    • __str__: 'Aldric (KK: 85)'

    • __repr__: "Held('Aldric', 85)" – eindeutige Darstellung fuer Debugging

    • __eq__: zwei Helden sind gleich wenn name und kampfkraft identisch sind

    • __lt__: ein Held ist kleiner als ein anderer wenn seine kampfkraft kleiner ist

  3. Teste:

a = Held('Aldric', 85)
b = Held('Aldric', 85)
c = Held('Lyria', 90)

print(a == b)          # True
print(a == c)          # False
print(a < c)           # True
print(sorted([c, a]))  # [Aldric, Lyria] -- __lt__ ermoeglicht sorted()

  1. Erklaere als Kommentar: Was ist der Unterschied zwischen __str__ und __repr__? Wann verwendet Python welche Methode?

Aufgabe 5 Vorhersage: Dunder-Methoden

Den Code nicht ausfuehren. Ausgabe als Kommentar schreiben, dann pruefen.

5.1

class Held:
    def __init__(self, name, hp):
        self.name = name
        self.hp   = hp

    def __str__(self):
        return f'{self.name}: {self.hp} HP'

    def __repr__(self):
        return f"Held('{self.name}', {self.hp})"

a = Held('Aldric', 100)
print(a)
print(repr(a))
print([a])

5.2

class Trupp:
    def __init__(self, helden):
        self._helden = helden

    def __len__(self):
        return len(self._helden)

    def __add__(self, other):
        return Trupp(self._helden + other._helden)

a = Trupp(['Aldric', 'Lyria'])
b = Trupp(['Thorn'])
c = a + b
print(len(a))
print(len(c))

5.3

class Held:
    def __init__(self, name, hp):
        self.name = name
        self.hp   = hp

    def __eq__(self, other):
        return self.hp == other.hp

a = Held('Aldric', 100)
b = Held('Lyria', 100)
c = Held('Thorn', 80)

print(a == b)
print(a == c)
print(a is b)
Aufgabe 6 Design Pattern: Factory

  1. Gegeben sind diese Klassen:

class Held:
    def __init__(self, name, hp, staerke):
        self.name = name; self.hp = hp; self.staerke = staerke
    def __str__(self): return f'{self.name} ({self.__class__.__name__}) HP:{self.hp}'

class Krieger(Held):
    def __init__(self, name): super().__init__(name, 120, 18)

class Magier(Held):
    def __init__(self, name): super().__init__(name, 70, 8)

class Waldlaeufer(Held):
    def __init__(self, name): super().__init__(name, 90, 14)

  1. Kopiere die Klassen. Schreibe eine Funktion erstelle_held(klasse, name), die anhand des Strings klasse das richtige Objekt erstellt. Bei unbekannter Klasse: ValueError.

  2. Teste:

party = [
    erstelle_held('krieger', 'Aldric'),
    erstelle_held('magier', 'Lyria'),
    erstelle_held('waldlaeufer', 'Thorn'),
]
for held in party:
    print(held)

  1. Erweitere die Factory so, dass sie auch 'paladin' unterstuetzt. Fuege dafuer eine Klasse Paladin(Krieger) hinzu.

  2. Erklaere als Kommentar: Was ist der Vorteil der Factory gegenueber direktem Aufruf?
