Aufgabe 1 Erste Klasse und Instanzen

  2. Erstelle zwei Objekte: aldric = Held() und lyria = Held().

  3. Gib type(aldric) aus.

  4. Pruefe mit isinstance(aldric, Held) ob aldric eine Instanz von Held ist.

  5. Pruefe mit aldric is lyria, ob beide Namen auf dasselbe Objekt zeigen.

  6. Erklaere als Kommentar: Was ist der Unterschied zwischen einer Klasse und einem Objekt?

Aufgabe 2 Konstruktor __init__ und Attribute

  1. Schreibe eine Klasse Held mit einem Konstruktor __init__, der die Parameter name, klasse, hp und staerke entgegennimmt und sie als Instanzattribute speichert.

  2. Erstelle drei Objekte:

aldric = Held('Aldric', 'Krieger', 100, 15)
lyria  = Held('Lyria',  'Magierin', 80, 12)
thorn  = Held('Thorn',  'Waldlaeufer', 90, 14)

  1. Gib folgende Werte aus:

    • aldric.name

    • lyria.klasse

    • thorn.hp

  2. Zeige, dass jede Instanz ihre eigenen Werte hat: Veraendere aldric.hp auf 50 und pruefe, dass lyria.hp unveraendert bleibt.

  3. Erklaere als Kommentar: Was passiert im Hintergrund wenn Held('Aldric', ...) aufgerufen wird?

Aufgabe 3 Methoden und self

Erweitere die Held-Klasse aus Aufgabe 2 um folgende Methoden:

  1. angreifen(self): gibt self.staerke * 2 zurueck und gibt eine Meldung aus, z.B. 'Aldric greift an und macht 30 Schaden!'

  2. erleidet_schaden(self, schaden): zieht schaden von self.hp ab. HP soll nie unter 0 fallen. Falls HP auf 0 sinkt: Meldung 'Aldric wurde besiegt!'

  3. heilen(self, menge): erhoht self.hp um menge. Nur positive Werte sollen wirken.

  4. ist_am_leben(self): gibt True zurueck wenn self.hp > 0, sonst False.

  5. Teste alle Methoden:

aldric = Held('Aldric', 'Krieger', 100, 15)
schaden = aldric.angreifen()       # 30
aldric.erleidet_schaden(80)
aldric.erleidet_schaden(50)        # sollte 'besiegt' ausgeben
print(aldric.ist_am_leben())       # False
aldric.heilen(10)                  # sollte keine Wirkung haben -- bereits besiegt? Oder doch?
                                   # Entscheide selbst und erklaere als Kommentar.

Aufgabe 7 Kapselung mit _-Konvention

  1. Schreibe eine Klasse Held in der _hp und _staerke als interne Attribute (mit fuehrendem Unterstrich) gespeichert werden.

  2. Stelle sicher, dass folgende Regeln eingehalten werden:

    • _staerke ist mindestens 1 (kein Held hat Staerke 0 oder weniger)

    • _hp faellt nie unter 0

    • Heilung ist nur mit positiven Werten moeglich

  3. Schreibe eine Methode hp (ohne Unterstrich) die den aktuellen HP-Wert zurueckgibt, damit man von aussen lesen kann ohne direkt zuzugreifen.

  4. Teste:

aldric = Held('Aldric', 'Krieger', 100, 15)
aldric.erleidet_schaden(150)   # HP soll 0 sein, nicht -50
print(aldric.hp())             # 0
aldric.heilen(-10)             # negative Heilung wird ignoriert
print(aldric.hp())             # immer noch 0

schwacher = Held('Wicht', 'Bauer', 10, 0)   # Staerke wird auf 1 gesetzt
print(schwacher._staerke)      # 1

  1. Erklaere als Kommentar: Was ist der Unterschied zwischen _hp und hp und warum ist diese Trennung nuetzlich?

Aufgabe 8 Methoden die andere Methoden aufrufen

  1. Schreibe eine vollstaendige Held-Klasse mit:

    • __init__: name, klasse, _hp, _staerke (Validierung wie in Aufgabe 7)

    • ist_am_leben: gibt True zurueck wenn _hp > 0

    • erleidet_schaden: ruft intern ist_am_leben auf – nur lebende Helden koennen Schaden nehmen

    • angreifen: gibt 0 zurueck wenn der Held besiegt ist, sonst _staerke * 2

    • heilen: heilt nur wenn der Held noch lebt

    • __str__: gibt den Status aus

  2. Teste das Zusammenspiel:

aldric = Held('Aldric', 'Krieger', 100, 15)
lyria  = Held('Lyria', 'Magierin', 80, 12)

# Kampfrunde
schaden = aldric.angreifen()
lyria.erleidet_schaden(schaden)

schaden = lyria.angreifen()
aldric.erleidet_schaden(schaden)

print(aldric)
print(lyria)

aldric = Held('Aldric', 'Krieger', 100, 15)

Aufgabe 10 Kombination: Kampfsimulator

  2. Der Verteidiger nimmt Schaden.

  3. Die Funktion gibt aus, was passiert ist.

  4. Die Funktion gibt True zurueck wenn der Verteidiger besiegt wurde, sonst False.

Schreibe dann eine Funktion kampf(held1, held2), die abwechselnd kampfrunde aufruft bis einer der Helden besiegt ist. Gib nach dem Kampf aus, wer gewonnen hat.

Teste:

aldric = Held('Aldric', 'Krieger', 100, 15)
lyria  = Held('Lyria',  'Magierin', 60, 18)

kampf(aldric, lyria)
