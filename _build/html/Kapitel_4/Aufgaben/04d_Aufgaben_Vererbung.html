Aufgabe 1 Einfache Vererbung und super()

  1. Schreibe eine Basisklasse Held mit:

    • __init__: name, hp, staerke

    • erleidet_schaden(schaden): zieht Schaden ab, HP nie unter 0

    • ist_am_leben(): gibt True zurueck wenn hp > 0

    • __str__: gibt 'Name (HP: x, STR: y)' zurueck

  2. Schreibe eine Klasse Krieger(Held) mit:

    • eigenem __init__: ruft super().__init__() auf, setzt zusaetzlich self.ruestung = ruestung (Parameter, Default 5)

    • ueberschreibt erleidet_schaden: zieht zuerst ruestung vom Schaden ab, dann erst die restlichen HP

  3. Teste:

basis  = Held('Basis', 100, 10)
aldric = Krieger('Aldric', 100, 15)

basis.erleidet_schaden(30)
aldric.erleidet_schaden(30)  # nur 25 Schaden wegen Ruestung=5

print(basis)
print(aldric)

  1. Erklaere als Kommentar: Was passiert wenn man super().__init__() vergisst?

  5. Paladin(Krieger): kombiniert Krieger-Ruestung und hat zusaetzlich heilen(), das 20 HP an einen uebergebenen Helden gibt
